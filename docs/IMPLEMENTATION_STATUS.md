# ScoreToKeys Kids 实现状态

> 版本：0.1.0  
> 日期：2026-08-19  
> 里程碑：M0 正式项目基础

## 已完成

### 正式仓库

- 独立项目路径和 Git 仓库；
- ScoreToKeys Kids 品牌、包名、页面标题和导出标识；
- npm lock、Node 版本约束和 Windows CI；
- 本地开发、测试、构建和预览命令；
- npm Registry 故障时带 SHA-256 校验的 unpkg 后备安装器。

### 已迁移的可运行闭环

- 原图和结构化结果并排校对；
- 音高、时值、歌词、指法和和弦编辑；
- 指法与和弦锁定；
- 动态规划右手指法；
- 调内和弦及四种左手模式；
- 统一演奏时间线；
- Web Audio、节拍器、调速和小节循环；
- MIDI、MusicXML、JSON 和浏览器 PDF；
- 键盘、左右手和谱面高亮；
- 基于音频输出时间戳的动画同步。

### 多模型识别基础

已建立不依赖供应商 API 的核心层：

- 版本化识别候选和证据契约；
- Reader A、Reader B、Judge 及模型配置档案；
- Reader 并行独立调用接口；
- 候选确定性校验；
- 缺事件、音级、八度、节奏、休止、歌词、拼写、结构和覆盖差异；
- 高风险分类；
- Judge 事件级选择；
- 合并结果重新校验；
- 显式 `reader-agreed`、`judge-confirmed` 和 `unresolved`；
- 不支持的模型配置显式记录；
- 多测试文件自动发现和执行。

当前没有供应商网络调用，也没有在浏览器中保存模型密钥。

### 来源感知 A4 基础

- 版本化 `A4LayoutPlan`；
- 原稿版式和放大练习模式；
- 来源谱行完整且唯一映射校验；
- 英文测试谱按原稿四行组织；
- 中文测试谱按原稿七行、每行五小节组织；
- 练习模式重新流式分组和自动分页；
- 动态小节宽度；
- 屏幕 A4 页面和打印分页；
- 当前谱行自动跟随；
- 用户滚动或点击后暂停跟随；
- 明确的“继续跟随”控制。

当前页面使用 React/HTML/CSS 渲染；完整 SVG 排版引擎属于 M2。

## Fixture 说明

`src/data/samples.ts` 中的两首测试曲是开发期人工校对 fixture。界面会明确显示该状态。它们用于领域、布局、播放和导出回归，不代表在线多模型识别准确率。
